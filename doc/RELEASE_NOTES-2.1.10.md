# shUnit2.1 2.1.8 Release Notes

Fork: https://github.com/TurtleEngr/shunit2
From: https://github.com/kward/shunit2

This release contains bug fixes and enhancements.

## New features

- Added ASCII Esc to turn off color changes, to limit the amount of
  color text. Now things are readable on GUIs with light backgrounds.

- Added env. var. SHUNIT_TRAP. Set it to 'n' to disable exit
  traps. This can be useful for debugging unit tests.
